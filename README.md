# Tsinjo - Tsinjovy ireo izay tsy manana

🇲🇬 **Ne gaspillez pas, partagez !** 

Plateforme de don et récupération d'invendus alimentaires à Madagascar.

## 🚀 Technologies

- React 18
- TypeScript
- Vite
- TailwindCSS
- Zustand
- Zod


## 🛠 Installation

```bash
# Cloner
git clone https://github.com/fatratra-png/itokiana-tsinjo-front.git

# Change direction to the cloned project
cd itokiana-tsinjo-front

# Installer
npm install

# Dev
npm run dev

# Build
npm run build

# Preview
npm run preview
